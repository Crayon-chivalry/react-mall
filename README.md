# React Mall

一个基于 React 的移动端商城项目，包含商品浏览、分类筛选、搜索、购物车、订单、地址管理和用户中心等常见功能。

## 技术栈

- React 18
- TypeScript
- Vite
- React Router
- Zustand
- Ant Design Mobile
- Axios
- Sass

## 功能模块

- 首页推荐与商品分类
- 商品列表、搜索与商品详情
- SKU 选择与购物车管理
- 订单确认、订单列表与订单详情
- 收货地址新增、编辑与管理
- 登录、注册、密码重置与个人设置

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发环境
npm run dev
```

其他常用命令：

```bash
# 类型检查并构建生产版本
npm run build

# 运行 ESLint
npm run lint
```
